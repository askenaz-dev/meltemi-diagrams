Meltemi Diagrams English

Dibujar con agentes de programación

La skill meltemi-diagrams enseña a Claude Code, Codex, Cursor, GitHub Copilot, Gemini CLI, Devin Desktop y otros agentes de programación a dibujar diagramas como código: escriben archivos .meltemi, los validan con la línea de comandos y corrigen lo que esta informa, en lugar de dibujar imágenes a mano. La skill trae un flujo de trabajo, una plantilla, las reglas que ahorran iteraciones, referencias del lenguaje, la disposición, los temas, C4, los diagramas de secuencia, las composiciones libres, las historias y la conversión, y ejemplos completos.

Un prompt

Pega esto en tu agente de programación, en tu proyecto. El agente lee el prompt de configuración, instala la skill para los agentes que usa tu proyecto, dibuja un diagrama de secuencia pequeño de uno de sus flujos, lo valida hasta que no queda ningún diagnóstico y te dice dónde quedó el SVG. El prompt está en inglés, el idioma en que el agente lee la guía; el agente te responde en el tuyo. 

Set up Meltemi Diagrams in this project so you can draw diagrams as code, and prove it works — you'll need terminal access on this machine and Node 22.12 or later. First read https://diagrams.meltemi.dev/agent-setup/prompt.md and follow it. Install the meltemi-diagrams skill for the coding agents this project uses (ask me if it's unclear which) with `npx @meltemi/diagrams-cli@latest skill install`. Then prove it: write a small sequence diagram of one flow of this project, validate it until no diagnostic remains, export the SVG, and show me the validation's last line and where the SVG is. Never sign in to the cloud, never print or commit a token, and don't commit or change my project's configuration beyond the skill folders without asking me first.

El prompt de configuración necesita la línea de comandos 1.10.0 o posterior; un agente que encuentra una anterior lo dice y se detiene. Un agente sin acceso a la web imprime el mismo texto con npx @meltemi/diagrams-cli@latest skill prompt.

Instalar la skill tú mismo

En la carpeta de tu proyecto, sin instalar nada:

npx @meltemi/diagrams-cli@latest skill install --agent <names>

O instala la línea de comandos una vez y ejecuta mdg skill install en cada proyecto: 

npm install --global @meltemi/diagrams-cli

<names> es uno o más nombres de la tabla, separados por comas, o all, el valor por defecto, para las dos carpetas. Una carpeta que comparten varios agentes se escribe una vez. --user escribe tus propias carpetas (~/.claude/skills, ~/.agents/skills), para todo proyecto. Una copia que ya está se conserva salvo que agregues --force, que reemplaza solo la carpeta de la skill. El comando escribe solo carpetas de skills, nunca AGENTS.md, CLAUDE.md ni otro archivo del proyecto.

Lo que el agente demuestra

Escribe un flujo real de tu proyecto como un diagrama de secuencia pequeño en diagrams/, o el inicio de sesión de mdg init --template sequence en una carpeta sin código que leer. Valida la hoja hasta que la última línea dice Checked 1 file: 0 errors, 0 warnings., exporta el SVG a su lado y te dice esa línea, dónde quedó el SVG y en qué carpetas quedó la skill.

Lo que nunca hace

  • Imprimir, leer, copiar ni confirmar en un commit un token (un valor mdg_…).
  • Iniciar sesión, hacer push, pull, publicar ni ejecutar otro comando de la nube salvo que lo pidas.
  • Hacer commit ni preparar nada, ni cambiar tu configuración, tu CI o los archivos de instrucciones de los agentes más allá de las carpetas de skills, sin preguntarte antes.
  • Agregar --force o --user por su cuenta.
  • Dibujar una imagen a mano, editar un SVG exportado ni reescribir una fuente de Mermaid o PlantUML, que mdg import convierte.
