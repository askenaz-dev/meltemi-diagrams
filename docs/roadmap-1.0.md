# Meltemi Diagrams 1.0 roadmap

Meltemi Diagrams 1.0 is the complete public version defined in
`propuesta-detallada-diagramas-como-codigo.pdf`. All of it is built now, as the ordered OpenSpec
changes below. Nothing in 1.0 is deferred to a later phase. The order only follows dependencies,
and each change is proposed, implemented, verified and archived before the next one starts.

The only exclusions are the ones the proposal itself makes for 1.0:

- realtime collaboration (it came after 1.0, in the playground's cloud projects:
  [working together](playground.md#working-together));
- synthetic voice;
- AI video generation;
- universal import;
- full conversion to editable PowerPoint shapes;
- PPTX export, which the proposal places after 1.0.

Work that only the product owner can do is listed at the end, with what the code provides for it.

## Owner actions the code prepares for

- Trademark search and final legal review of the name.
- Publishing: the npm organisation, the VS Code Marketplace and Open VSX publisher accounts, and the release itself. Change 24 leaves every package ready and documents the commands.
- Running the pilot with five to eight users. Change 24 provides the protocol and measurement templates.
- Checking exports in PowerPoint, Keynote and Google Slides on real machines. Change 23 provides the files, the checklist and the results table.
- Supplying corpus material from the existing PlantUML tool. Change 12 includes it when provided.
