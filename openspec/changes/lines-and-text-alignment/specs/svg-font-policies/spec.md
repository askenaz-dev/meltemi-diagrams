## ADDED Requirements

### Requirement: A hand font for sketch themes
Once the owner approves its download, `@meltemi/diagrams-fonts` SHALL bundle a fourth family, Patrick Hand (SIL Open Font License 1.1, from `@fontsource/patrick-hand`, weight 400), measured and embedded as the three families are: its subsets embedded with `unicode-range` under `embedded`, its outlines under `outlined`, a weight it lacks measured and embedded with 400, the licence inventory regenerated by `pnpm licenses:inventory`, and `docs/language/fonts.md` listing it. The `sketch.light` and `sketch.dark` themes SHALL then name it first in `font`; until it is bundled they SHALL name Inter, so no sketch picture carries `layout.unmeasured-font`.

#### Scenario: Embedded hand font
- **WHEN** a diagram with `theme "sketch.light"` is rendered with `embedded` after the font is bundled
- **THEN** the `<style>` holds a `@font-face` rule for `Patrick Hand` 400 with a `data:font/woff2;base64,` source and a `unicode-range`, and labels of weight 600 use that rule

#### Scenario: Outlined hand font
- **WHEN** the same diagram is rendered with `outlined`
- **THEN** it contains no `<text>`, and each label is a `<path aria-label="…">` whose width equals the measured width within 0.5 px

#### Scenario: Before the font lands
- **WHEN** a diagram with `theme "sketch.light"` is laid out while the bundle has three families
- **THEN** its text is measured with Inter and no `layout.unmeasured-font` is reported

#### Scenario: Inventory out of date
- **WHEN** the font package is added and `pnpm licenses:inventory` is not run
- **THEN** the release check fails naming `THIRD_PARTY_LICENSES.md`
