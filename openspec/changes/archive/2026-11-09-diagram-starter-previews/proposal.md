# Illustrated choices in New diagram

## Why

The seven choices currently use small monochrome icons. The owner cannot tell what each kind
will look like and requested color and a preview in the creation dialog.

## What changes

Show a distinct colored miniature for each of the seven choices, alongside its existing name
and description. Present the drawings as examples of what can be created, rather than exact
snapshots of the initially empty document. Keep the form compact, keyboard accessible and usable
at 320 pixels, in English/Spanish and light/dark themes.

## Capabilities

- Modified: `project-explorer` — illustrated, accessible starter selection.

## Impact

Browser New diagram dialog, lightweight local SVG illustrations, scoped styles and localized
hint, browser regressions and user guidance. No creation semantics, dependency, account,
project configuration, cloud or private-project change.
