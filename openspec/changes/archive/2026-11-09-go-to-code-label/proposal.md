# Name source navigation Go to code

## Why

The canvas action "Show in text" can sound like displaying a diagram's visible text. The action
actually navigates to the selected element's declaration in the code editor.

## What changes

Use "Go to code" in English and "Ir al código" in Spanish throughout the shared canvas menus.
Update the editor guide, current specifications and browser assertions to use the same wording.
This is a post-1.0 wording change outside the numbered roadmap.

## Non-goals

The separate local-mcp-server change owns local MCP server behavior.
