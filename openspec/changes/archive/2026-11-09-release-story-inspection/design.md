# Design

The packaged CLI is the distribution boundary. Derive expected folder tool names from the
canonical tool definitions, then call `inspect_story` against the generated purchase project.
Verify meaningful compiled timeline content and its source revision; retain the existing preview
and shutdown checks. Regressions must reject a missing inspection tool or invalid report.

Keep all release gates and artifact recovery conditions. FFmpeg setup has a ten-minute step
limit, two acquisition retries and thirty-second HTTP/HTTPS timeouts. Use the same Ubuntu mirror
replacement as CI rather than introducing another installer or changing package versions.
