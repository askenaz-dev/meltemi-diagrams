## Why

The product owner closed the last provisional names on 2026-10-10: the command is `meltemi-diagrams` with the short alias `mdg`, and the npm packages live under the Meltemi family scope as `@meltemi/diagrams-*`. Every later change of the 1.0 roadmap adds packages, commands and documentation, so the names must be final before that work starts.

## What Changes

Roadmap change **2** (`docs/roadmap-1.0.md`), part of **Stage 6 (release preparation: naming)** done first because every other change builds on it.

- The CLI installs two binaries, `meltemi-diagrams` and `mdg`, which behave identically. Help, usage and error messages name `meltemi-diagrams`, and the help text mentions the `mdg` alias.
- The root script `pnpm studio` becomes `pnpm mdg`.
- The packages are renamed:

  | Before | After |
  |---|---|
  | `@dac/language` | `@meltemi/diagrams-language` |
  | `@dac/model` | `@meltemi/diagrams-model` |
  | `@dac/edit` | `@meltemi/diagrams-edit` |
  | `@dac/layout` | `@meltemi/diagrams-layout` |
  | `@dac/render` | `@meltemi/diagrams-render` |
  | `@dac/cli` | `@meltemi/diagrams-cli` |

  Folders under `packages/` keep their short names.
- The export condition that resolves workspace packages to their TypeScript sources becomes `@meltemi/diagrams-source`, in package exports, `tsconfig.base.json`, the root scripts and the vitest aliases.
- Documentation, the agent skill, the CI workflow, the OpenSpec project context and the two proposed changes (`vscode-extension`, `import-mermaid-plantuml`) use the new names. Decision 0002 records the final names.

## Capabilities

### New Capabilities
- `cli-binary`: the installed command names, the alias, and the name shown in help, usage and version output.
- `package-names`: the npm scope and naming of every workspace package and the source export condition.

### Modified Capabilities
- `cli-validation`: the command is invoked as `meltemi-diagrams validate`.
- `cli-export`: the command is invoked as `meltemi-diagrams export`.

## Impact

- Every `package.json`, every import of a workspace package, `PACKAGE_NAME` constants, `tsconfig.base.json`, `vitest.config.ts`, root scripts, the lockfile (regenerated by `pnpm install`), and the CI workflow.
- `CLI_NAME` and the help text in `packages/cli/src/cli.ts`, plus the CLI tests that assert messages.
- No behaviour change besides names. No new dependencies.

## Non-goals

- Renaming the `studio.light` and `studio.dark` theme ids. Themes are redesigned in roadmap change 6 (`styles-themes-icons`).
- Publishing packages or registering the npm organisation, which is an owner action prepared by roadmap change 24 (`release-1-0`).
