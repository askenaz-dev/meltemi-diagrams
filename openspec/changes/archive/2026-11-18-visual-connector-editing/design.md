## Import lifecycle

The browser playground closes the source dialog when it creates and opens a file. Its result status provides access to the report, including findings and the Markdown download. A conversion that produces no sheet retains the editable source and displays its diagnostics in place.

## Connector geometry and edit transactions

The shared canvas grows the screen-space hit area for endpoints and exposes the existing filtered picker for changing either end. Dragging offers the existing outline and port snapping. The `CanvasAction.setEnd` protocol remains the entry point for both methods. The editor session and edit planner keep the selected relation and preserve unrelated declarations and route data when writing the source.

## Alignment

The editor computes alignment and guide snapping from the displayed geometry with the coordinate precision supported by placement statements. Materializing the current automatic arrangement uses the positions already displayed and preserves explicit routes. Layout recomputation keeps its existing behavior.
